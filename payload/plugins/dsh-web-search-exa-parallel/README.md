# Exa → Parallel для DSH

Автономный провайдер поиска без ключа: сначала Exa, при ошибке или отсутствии пригодных результатов — Parallel. Запросы отправляются внешним сервисам; их бесплатная доступность, квоты и условия могут измениться без предупреждения. Гарантий доступности нет. Версия 1 не поддерживает дополнительные учётные данные или настройку адресов. Результаты сторонних сервисов следует считать недоверенными.

Каждый запрос Parallel независим: идентификатор сессии не сохраняется и не передаётся, поскольку интерфейс DSH не предоставляет идентификатор разговора. Это исключает смешивание разных пользовательских сессий, но не использует возможности продолжения контекста Parallel. Интерфейс настройки отсутствует.

Реализация написана самостоятельно по описанному протоколу MCP JSON-RPC (`tools/call`) и форматам ответов Exa и Parallel; код OpenCode не использовался. Лицензия MIT.
