# DSH Setup для macOS

Локальный мастер установки пользовательской конфигурации DeepSeek Harness и Oh My DSH Slim. **Это не дистрибутив приложения DeepSeek Harness.**

## Установка

Откройте «Терминал» и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/egor-malishevski/dsh-installer/main/install.sh | bash
```

Если DeepSeek Harness ещё не установлен, скрипт сначала скачивает официальную сборку 0.2.1-rc.5 для Apple Silicon с `download.deepseek.com` (около 350 МБ). Затем сверяет SHA-512 с суммой из фида обновлений DeepSeek, проверяет версию, bundle ID и подпись DeepSeek (Team `NAN929V4UM`) и кладёт приложение в `/Applications`. Уже установленное приложение скрипт не изменяет. Если его версия отличается от 0.2.1-rc.5, выводится предупреждение. DeepSeek удаляет старые сборки, поэтому после выхода новой версии загрузка rc.5 может перестать работать. Для Mac на Intel сборки 0.2.1-rc.5 нет.

Затем скрипт скачивает архив мастера из GitHub Releases, сверяет его SHA-256 с суммой, записанной в `install.sh`, распаковывает во временную папку и открывает мастер в браузере. Когда установщик закрывается, временная папка удаляется. Права администратора (`sudo`) не нужны.

Если нужно только проверить окружение, без запуска мастера:

```bash
curl -fsSL https://raw.githubusercontent.com/egor-malishevski/dsh-installer/main/install.sh | bash -s -- --check
```

### Почему не нужны подпись и Apple Developer

Мастер только настраивает официальный DeepSeek Harness. Само приложение скачивается с сервера DeepSeek без изменений, подписано и нотаризовано DeepSeek, и установщик его не изменяет. Gatekeeper проверяет файлы с атрибутом карантина, а его получают файлы, скачанные браузером. У файлов, загруженных через `curl`, этого атрибута нет, поэтому macOS не блокирует запуск.

### Без интернета

Скачайте `dsh-installer-<версия>.tar.gz` со страницы Releases, распакуйте архив и выполните `bash Install.command` в папке распаковки. Если архив скачан браузером, двойной клик по `Install.command` macOS заблокирует. Явный запуск через `bash` работает.

### Для разработчика

`npm test` запускает тесты. `npm run package` собирает `dist/dsh-installer-<версия>.tar.gz`, файл `.sha256` и записывает версию и сумму в `install.sh`. Архив загружается в Release с тегом `v<версия>`, затем коммитится обновлённый `install.sh`.

## Требования

- macOS на Apple Silicon и официальный **DeepSeek Harness 0.2.1-rc.5** в `/Applications/DeepSeek Harness.app`. Если приложения нет, команда установки скачает его сама.
- Harness обновляется автоматически. Мастер принимает только 0.2.1-rc.5, а работа установленной конфигурации на более новых версиях не проверялась.
- Собственный CLIProxyAPI: адрес API и API Key. Пароль панели управления CLIProxyAPI — не API Key.
- Чистый профиль Desktop. Установщик не предназначен для перезаписи или обновления существующей сборки.
- Для выбранных MCP могут потребоваться дополнительные программы, доступ к сети и отдельная авторизация.

Версия Harness закреплена из-за локального клиента наблюдения за соединениями MCP. При обновлении Harness совместимость нужно проверить заново.

## Порядок настройки

1. Разверните CLIProxyAPI по [инструкции Render / Git Storage](https://help.router-for.me/hands-on/tutorial-10.html). Репозиторий с конфигурацией и авторизацией должен быть **приватным**. GitHub-токен и пароль управления вводятся на стороне сервиса, а не в этом мастере.
2. Введите API URL и API Key вашего CLIProxyAPI.
3. Выберите необходимые MCP и задайте новые параметры. По умолчанию ни один MCP не выбран. GitLab и Bitbucket можно выбрать независимо, в том числе вместе.
4. Проверьте роли и модели Oh My DSH Slim.
5. Закройте Harness через **⌘Q**, выполните проверки и подтвердите установку.

Наличие модели в настройках не означает, что она доступна в вашем аккаунте CLIProxyAPI. Авторизуйте нужные аккаунты на стороне CLIProxyAPI. Для Explorer с `deepseek-account/deepseek-flash` дополнительно требуется вход в DeepSeek Account внутри Harness.

## Начальные назначения

| Назначение | Модель | Reasoning |
|---|---|---|
| Основная сессия | CLIProxyAPI / Claude Opus 5.5 | Настройка сессии |
| Orchestrator | Наследует основную модель | high |
| Oracle | CLIProxyAPI / GPT-6.1 Sol | high |
| Designer | CLIProxyAPI / Claude Sonnet 5.5 | medium |
| Fixer | CLIProxyAPI / Claude Sonnet 5.5 | medium |
| Explorer | DeepSeek Account / DeepSeek Flash | low |
| Librarian | CLIProxyAPI / Grok 4.7 | Не задаётся |

Общие разрешения ролей ограничиваются выбранными MCP и конкретными инструментами чтения. Они не создают отдельных подключений. Designer получает чтение макетов Figma (`get_figma_data`), Explorer и Librarian — поиск документации Context7. Obscura, Memory, Google Sheets и Sequential Thinking остаются у основной сессии. GitLab настраивается в режиме `readonly`.

Для Figma нужен персональный токен Figma. API-ключ Context7 необязателен: без него действуют бесплатные лимиты запросов.

## Веб-поиск через DeepSeek Account

Плагин `web-search-account` включает инструмент `web_search` во всех сессиях, на какой бы модели они ни работали. Поиск идёт через вход в DeepSeek Account внутри Harness, поэтому без входа в аккаунт поиск работать не будет. Загрузка страниц (`web_fetch`) идёт напрямую по HTTP.

## Что не переносится

- Корпоративные плагины и провайдеры исходного компьютера, а также их ключи.
- Личные API-ключи, корпоративные адреса и учётные данные исходного компьютера.
- Сессии, журналы, сохранённая Memory, cookies и браузерный профиль Obscura.
- Настройки OpenCode, бинарник Harness и содержимое `app.asar`.

Мастер работает локально на `127.0.0.1`. Доступ к его API защищён случайным токеном текущего запуска. Не пересылайте адрес открытого мастера. Ключи не должны попадать в скриншоты, URL или журналы. После работы закройте вкладку и остановите установщик в терминале через `Ctrl+C`.

## Состояние разработки

Сборка ещё проходит интеграцию и не объявлена готовой к установке на другой компьютер. До итоговой проверки не используйте её для рабочего профиля. Завершённые проверки отдельных компонентов не заменяют проверку полного пути установки.

## Лицензии

Лицензии сторонних компонентов сохранены в `payload`, включая MIT-лицензии Oh My DSH Slim и встроенной копии MCP-клиента DeepSeek. Локальная интеграция включена как часть пользовательской сборки; это не заявление о лицензии на публичное распространение. Дополнительные MCP загружаются или устанавливаются отдельно и имеют собственные лицензии.
